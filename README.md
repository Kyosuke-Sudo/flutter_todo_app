# アプリの名称
ToDo

# アプリの概要
シンプルなToDoアプリ

# 機能
- タスクの作成
- タスクの完了
- タスクの削除

# 操作方法
- タスクの作成：画面下部の入力欄にタスクを入力して追加ボタンを押す
- タスクの完了：右か左にスワイプ
- タスクの削除：タスクの長押し
- タスクの編集：ダブルタップ
